# Tavla · Gizlilik ve KVKK

Tavla uygulamasının KVKK aydınlatma metni ve gizlilik politikası. Asıl adres artık stüdyonun sitesi:
https://fernwoodstudio.net/tavla/gizlilik/ (English: https://fernwoodstudio.net/tavla/gizlilik/en.html)

Bu sayfa (https://muhtaraga.github.io/tavla-legal/) uygulamanın eski sürümleri bu adresi açtığı için
aynı metinle güncel tutulur.

Sayfalar uygulama deposundaki metinden üretilir (`apps/mobile/scripts/generate-privacy-page.mjs`);
burada elle düzenlenmez.
